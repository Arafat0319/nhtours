- **改密码 / SSH / 审计日志**
    - → [安全手册.md](安全手册.md)（无网页改密；用 Actions 或 SSH）

## 二、快速开始

- **流程**

    ```text
    登录后台 → 创建行程（7 步向导）→ 发布 → 把链接发给客户
    ```

- **步骤**
    - 1 — 打开 https://nhtours.com/admin/login，输入用户名密码
    - 2 — **My Trips** → **+ New Trip**，按向导填完并 **发布**
    - 3 — 复制行程链接发给客户，客户在线报名付款

## 三、后台管理

- **仪表盘 Dashboard**
    - 总行程数、总预订数、近期订单

- **行程 My Trips**
    - **列表**
        - 卡片视图 / 日历视图
        - 筛选：Upcoming、Past、Draft
    - **新建 Trip Builder（7 步）**
        - 1 — 基础信息：标题、日期、封面、人数、**Trip abbreviation**（订单号缩写，如 `MT`；一般自动生成，可手改；只影响之后的新订单）
        - 2 — 详细描述
        - 3 — 套餐与价格（全款 / 分期）
        - 4 — 附加选项
        - 5 — 购买者信息字段
        - 6 — 参与者问卷
        - 7 — 折扣码
    - **行程内操作**
        - **Messages**：本 trip 人工群发邮件（New Message）；Sent 不含系统催款/确认信
            - 收件人是 **booking contact / 买家邮箱**（不是每位参与者）
            - Send to：Everyone / 指定套餐或附加 / 有尾款或逾期 / 问卷未完成 / 缺签名 / Specific / **键入邮箱**（逗号或换行，不限本行程）
            - Sender name：客户收件箱显示名（默认 Nexus Horizons Tours）；发信地址仍是系统 noreply（本地可为测试邮箱）
            - Reply-to：界面显示 **info@nhtours.com**；若本地用个人 Gmail 当地址发信，系统会自动把实际 Reply-To 对齐到发件邮箱，减轻进垃圾箱（生产应用公司域名 noreply 发信）
            - 可 **立即发送** 或 **Schedule**（flatpickr 选日期+时间，到期自动发出）；Drafts / Scheduled 可 Edit、Delete；Scheduled 可 Cancel 回草稿；Sent 可查看详情
            - 本期不支持附件
            - **少进垃圾箱**：生产请在 SES 验证 `nhtours.com`（DKIM）+ `SENDER_EMAIL=noreply@nhtours.com`，并移出沙箱；本地用个人 Gmail 测试时请查 Spam

- **订单（Manage Bookings）**
    - **Order number（业务单号）**
        - 形如 `2612MT-001`：出发年月 + 行程缩写 + 该行程内序号
        - 付款成功（或后台 Manual Booking）后生成，之后**不会**因改标题 / 改期而变化
        - 取消订单**不回收**序号（下一单继续往后编）
        - 列表与详情：大号显示 Order number，下方小字 `id: …`（内部用，客户看不到）
        - **Balance due**：列表中显示该单剩余未付；有尾款为琥珀色金额，已付清为 `$0`，已取消为 `-`
        - 页面顶部 **Balance due** 为该行程全部订单的未付合计
        - 搜索框可按姓名、邮箱或 Order number 查找
    - **状态**
        - Pending — 待支付
        - Deposit Paid — 已付定金
        - Fully Paid — 全额已付
        - Cancelled — 已取消
    - **退款**
        - 订单详情 → **Refund**
        - 选择要退的那一笔 **Payment**（定金 / 尾款等）
        - **卡手续费永不退**；可退金额按净额（基础金额）计算
        - 默认**不退定金**；若要退定金需勾选 **Also refund deposit**
        - 选择全额剩余或输入部分金额（上限随是否退定金变化）
        - **填写原因**（必填）
        - 可选：退款后取消订单；或 **Manual only**（只记本地、不调 Stripe）
        - **$0 订单**：无可退 Payment 时，勾选 Cancel booking + 填写原因即可取消（不调 Stripe）

- **客户 Customers**
    - Customers — 已预订客户
    - Leads — 咨询未订客户
    - Testimonials — 首页评价 / Feedback 审核（批准后上首页轮播）

- **报表 Reports**
    - 总收入、各行程明细、待收款项

## 四、客户报名

- **客户步骤（行程页弹窗）**
    - 1 — 选套餐、人数、全款或分期
    - 2 — 附加选项（单房差、接机等）
    - 3 — 参与者信息
    - 4 — 购买者信息
    - 5 — Stripe 支付（或定金刚好被折扣抵成 $0 时直接确认）

- **支付**
    - 由 Stripe 处理（PCI DSS）
    - 支持 Visa / Mastercard / Amex
    - **当前生产为 Test（沙盒）模式**；真实收款（Live）尚未开通

- **分期**
    - 先付定金 → 按约定付余款 → 到期前系统发提醒邮件（须配置 SES 后邮件才会真正发出）

- **确认与收据**
    - 邮件与 PDF 收据上的编号是 **Order number**（不是内部 id）

## 六、常见问题

- **Q：如何修改已发布行程？**
    - 行程管理页 → **Edit** → 修改 → 保存

- **Q：Order number 和旁边的 id 有什么区别？**
    - Order number 给客户看、对账用（如 `2612MT-001`）
    - `id` 是系统内部主键；链接和 API 仍用它，一般不用告诉客户

- **Q：改了行程标题或出发日，旧订单号会变吗？**
    - **不会**。旧号已锁定；新缩写 / 新出发月只影响之后的新订单

- **Q：如何导出订单？**
    - 行程管理页 → **Download Excel** → 下载当前快照（打开即有数据，无需刷新）
    - 含 **Participants** / **Contact** / **Bookings Summary** / **Canceled**
    - Summary 含 Order number、Expected、**Payments Received**、**Refunds**、**Net Paid**、**Balance due**、Status
    - 已退款/已取消订单会列出退款金额；取消参与者另见 **Canceled** 表
    - 表尾有合计与 Collected Funds 摘要（活跃单 Expected / Net；退款合计含取消单）
    - 列宽按内容自动撑开；金额为数字，可在 Excel 里再求和/筛选
    - 表头深灰白字风格参考 WeTravel 导出

- **Q：如何改管理员密码？**
    - 网页上没有改密入口
    - 见 [安全手册.md](安全手册.md) → 轮换凭据（GitHub Actions 或 SSH）

- **Q：分期逾期怎么办？**
    - 到期前 3 天、1 天发提醒（SES 配置后）
    - 逾期标为 Overdue；后台可查看

- **Q：退款多久到账？**
    - 后台发起 Stripe 退款后，通常 5–10 个工作日到客户卡上
    - Manual only 仅改系统账本，需另行在 Stripe / 银行处理

- **Q：定金能退吗？**
    - 默认不退：Refund 弹窗中「Also refund deposit」默认不勾选
    - 需要退定时由管理员勾选后再选金额；仍请对照 Terms / 客户约定

- **Q：折扣码怎么用？**
    - Trip Builder 第 7 步创建
    - 客户在支付页输入，系统自动算价

- **Q：安全日志 / SSH 怎么查？**
    - 见 [安全手册.md](安全手册.md)（`ssh nhtours`、`nh-audit` / `nh-audit -a`）
