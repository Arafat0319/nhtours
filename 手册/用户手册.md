## 二、快速开始

```text
登录后台 → My Trips → + New Trip（7 步）→ 发布 → 把行程链接发给客户
```

1. 打开 https://nhtours.com/admin/login  
2. **My Trips** → **+ New Trip**，填完并发布  
3. 复制 `/trips/...` 链接发给客户，客户在线报名付款

## 三、后台管理

### 仪表盘

总行程数、总预订数、近期订单。

### My Trips

- **列表**：卡片 / 日历；筛选 Upcoming、Past、Draft  
- **Trip Builder（7 步）**  
  1. 基础信息（标题、日期、封面、人数、**Trip abbreviation** — 订单号缩写，如 `MT`；只影响之后新单）  
  2. 描述  
  3. 套餐与价格（全款 / 定金+分期）  
  4. 附加选项  
  5. 购买者信息字段  
  6. 参与者问卷  
  7. 折扣码  

### Messages（行程内群发）

- 对象：本 trip 的**买家邮箱**（不是每位参与者）  
- Send to：Everyone / 套餐或附加 / 有尾款或逾期 / 问卷未完成 / 缺签名 / Specific / **键入邮箱**  
- 可立即发送或 **Schedule**；Drafts / Scheduled 可编辑删除；**本期无附件**  
- 生产发件：`noreply@nhtours.com`（SES）；Reply-to 一般为 `info@nhtours.com`  
- Sent 列表不含系统催款 / 自动确认信  

### Manage Bookings（订单）

| 项 | 说明 |
|----|------|
| Order number | 付款成功或 Manual Booking 后生成；改标题 / 改期**不改**旧号；取消**不回收**序号 |
| 列表 | 大号 Order number + 小字内部 id；可搜姓名、邮箱、Order number |
| Balance due | 单行：剩余未付（有尾款琥珀色；付清 `$0`；取消 `-`）；页顶为行程合计 |
| 状态 | Pending / Deposit Paid / Fully Paid / Cancelled |

#### 退款

1. 订单详情 → **Refund**  
2. 选择要退的那一笔 Payment（定金 / 尾款等）  
3. **卡手续费永不退**（按基础金额算可退上限）  
4. 默认**不退定金**；要退定金须勾选 **Also refund deposit**  
5. 选全额剩余或输入部分金额；**原因必填**  
6. 可选：退款后取消订单；或 **Manual only**（只改本地账、不调 Stripe）  
7. **$0 订单**：无可退 Payment 时，勾选 Cancel booking + 填原因即可取消（不调 Stripe）  

### Customers

- Customers — 已预订  
- Leads — 咨询未订（Contact 表单）；列表分页；超长邮箱 / 留言可 **Show more** 展开；三点菜单改状态 / 归档 / 删除；**勾选可批量删除**（管理员）；新提交会邮件通知 `RECIPIENT_EMAIL`（品牌卡片式，可点 Open in Leads）  
- Testimonials — 首页 / Feedback 审核（批准后上轮播）；**勾选可批量删除**（含已批准时会额外提醒）  
- **管理员通知邮件**（Contact / Newsletter / Testimonial / Feedback / Security）统一品牌卡片；**客户邮件**：收据、分期催款、Booking 单发、Messages 群发均为深蓝顶栏品牌壳（Messages 正文仍为编辑器内容）  

### Reports

总收入、行程明细、待收款项。

## 四、客户报名

客户在行程页点 Book Now，弹窗内完成：

| 步 | 内容 |
|----|------|
| 1 | 选套餐、人数（Travelers ±）；有分期时看 Payment Schedule |
| 2 | 附加选项（如有） |
| 3 | 参与者信息（含护照等上传） |
| 4 | 购买者信息 |
| 5 | 支付：Stripe 刷卡；若折扣把「现在应付」抵成 **$0**，则无需刷卡直接确认 |

右侧 **Your Booking**：可输入折扣码；Trip Total 为行程总价，Due at Booking 为本次应付。

**支付**：Visa / Mastercard / Amex；由 Stripe 处理。**现网为 Test 模式**，真实收款（Live）尚未开通。

**分期**：先付定金 → 按约定付余款 → 到期前系统发提醒邮件。

**确认与收据**：

- 邮件标题一般为 Payment Receipt；编号为 **Order number**  
- 邮件含 **PDF 附件**，以及蓝色按钮 **Download Receipt (PDF)**（链接带签名 token，不能仅凭订单数字 id 下载）  
- 若按钮失效：仍可用邮件附件；或联系客服并提供 Order number

## 六、常见问题

**如何改已发布行程？**  
行程管理 → **Edit** → 保存。

**Order number 和 id 有何区别？**  
Order number 给客户与对账；`id` 是系统主键（链接 / API 用），不必告诉客户。

**改标题或出发日，旧订单号会变吗？**  
不会。新缩写 / 新出发月只影响之后的新单。

**如何导出订单？**  
Manage → **Download Excel** → 静态快照（Participants / Contact / Bookings Summary / Canceled）。Summary 含 Expected、Payments Received、Refunds、Net Paid、Balance due；打开即可用，无需「刷新数据源」。

**如何改管理员密码？**  
网页无入口；见 [安全手册.md](安全手册.md) → 轮换凭据。

**分期逾期怎么办？**  
到期前 3 天、1 天发提醒；逾期标为 Overdue，后台可查。

**退款多久到账？**  
走 Stripe 的退款通常 5–10 个工作日到卡；Manual only 只改系统账，需另行处理银行 / Stripe。

**定金能退吗？**  
默认不退；管理员勾选 **Also refund deposit** 后方可退定金部分。请同时对照合同 / Terms。

**折扣码怎么用？**  
Trip Builder 第 7 步创建；客户在弹窗 Your Booking 输入。

**客户说收据下不了 / 样式没更新？**  
先让对方对网站 **Ctrl+F5**；收据按钮应直接下载 PDF。仍异常时提供 Order number 与发生时间。

**安全日志 / SSH？**  
见 [安全手册.md](安全手册.md)（`ssh nhtours`、`nh-audit`）。
