## 二、快速开始

```text
登录后台 → My Trips → + New Trip（7 步）→ 发布 → 把行程链接发给客户
```

1. 打开 https://nhtours.com/admin/login  
2. **My Trips** → **+ New Trip**，填完并发布  
3. 复制 `/trips/...` 链接发给客户，客户在线报名付款

## 三、后台管理

### 仪表盘

总行程数、总预订数、近期订单。

### My Trips

- **列表**：卡片 / 日历；筛选 Upcoming、Past、Draft  
- **Trip Builder（7 步）**  
  1. 基础信息（标题、日期、封面、人数、**Trip ID** — 订单号前缀缩写，如 `MT`；只影响之后新单）  
  2. 描述  
  3. 套餐与价格（全款 / 定金+分期）  
  4. 附加选项  
  5. 购买者信息字段  
  6. 参与者问卷  
  7. 折扣码  

### Messages（行程内群发）

- 对象：本 trip 的**买家邮箱**（不是每位参与者）  
- Send to：Everyone / 套餐或附加 / 有尾款或逾期 / 问卷未完成 / 缺签名 / Specific / **键入邮箱**  
- 可立即发送或 **Schedule**；Drafts / Scheduled 可编辑删除；**本期无附件**  
- 生产发件：`noreply@nhtours.com`（SES）；Reply-to 一般为 `info@nhtours.com`  
- Sent 列表不含系统催款 / 自动确认信  

### Payments

| 标签 | 包含 |
|------|------|
| **Full Payments** | 以 **订单** 为单位：① 一次付全款；② **定金 + 单笔尾款**（可展开看 Final payment；未付期可 Reminder / Mark Paid） |
| **Installment Payments** | 以 **订单** 为单位：定金后 **大于 1 期** 的分期计划（可展开各期；未付期可 Reminder / Mark Paid） |
| 其它 | 已付期不可催缴；Payment ID 仅在详情；报名用了优惠码时在定金/全款行与详情显示 Discount |

### Manage：Bookings 与 Participants

同一行程 Manage 下两个 Tab，**不要当两张订单表**：

| Tab | 看什么 |
|-----|--------|
| **Bookings** | 订单与钱：买家、Payment Type / Status、已付/欠款、人数汇总、订单级 Add-ons |
| **Participants** | 出行人花名册：姓名、邮箱、Gender / DOB / Registration Type、行程自定义题（如护照）、本人 Add-ons；用 **Order number** 点开对应订单 |

付款状态、买家、套餐、预订日期只在 **Bookings**（或 Excel 导出）查看；Participants 顶部仅按姓名 / 邮箱 / 订单号搜索。

### Manage Bookings（订单）

| 项 | 说明 |
|----|------|
| Order number | 付款成功或 Manual Booking 后生成；改标题 / 改期**不改**旧号；取消**不回收**序号 |
| 列表 | Order number；可搜姓名、邮箱、Order number |
| Balance due | 单行：客户仍应付（有尾款琥珀色；付清 / 退款后不欠 `$0`；取消 `-`）。退款会降低 Amount paid，**不会**把已退金额算成新欠款；页顶为行程合计 |
| 页顶合计 | Gross / Discount（有才显示）/ Expected / Amount paid / **Refunded**（有退款才显示）/ Balance due |
| 状态 | 列表展示：Pending / Deposit Paid / Fully Paid / **Overdue** / **Partially Refunded** / **Fully Refunded** / Cancelled（按已收款自动分辨部分/全部退款；Overdue=有过期未付分期且仍欠款） |
| Payment Type | **Full**（一次付清）/ **Deposit + Final**（定金+单笔尾款）/ **Installment (N)**（定金后 N 期，N>1） |
| Payment Status | 订单详情下拉仅付款进度：Pending / Deposit Paid / Fully Paid（**不含** Cancelled） |

#### 取消订单

1. 订单详情 → **Cancel order**（原 Reconcile 位置）→ 确认  
2. 订单标为 Cancelled，未付分期停止；**不自动退款**（要退钱用 Refund）  
3. **不会自动发邮件**；需通知请用 Messages  

也可在 **Refund** 弹窗勾选 **Cancel booking**（退款同时取消，或 $0 / 不退款仅取消并填原因）。

#### 查看退款明细

Payments → 打开对应 **Payment**（View）→ 顶部 **Refund Details**：已退总额、最新原因/时间；多笔退款时有历史表（金额、原因、是否 Manual only、Stripe Refund ID）。

#### 退款

1. 订单详情 → **Refund**  
2. 系统显示 **Refundable total**；可勾选 **Full refund** 自动填入剩余可退总额，或手动填写谈好的金额（不超过可退总额；卡费不退；多笔收款时系统自动分摊）。超过可退总额会即时红字提示，且无法提交  
3. **原因必填**（须 **admin** 角色才能退款；staff 会失败）  
4. 可选：退款后取消订单；或 **Manual only**（只改本地账、不调 Stripe）  
5. **$0 订单**：无可退余额时，勾选 Cancel booking + 填原因即可取消（不调 Stripe）；或直接用 **Cancel order**  
6. **不会自动发邮件**给客户（退款到卡由 Stripe 处理）。若需通知客户，请用 **Messages** 或另行联系  

### Customers

- Customers — 已预订  
- Leads — 咨询未订（Contact 表单）；列表分页；超长邮箱 / 留言可 **Show more** 展开；三点菜单改状态 / 归档 / 删除；**勾选可批量删除**（管理员）；新提交会邮件通知 `RECIPIENT_EMAIL`（品牌卡片式，可点 Open in Leads）  
- Testimonials — 首页 / Feedback 审核（批准后上轮播）；**勾选可批量删除**（含已批准时会额外提醒）  
- **管理员通知邮件**（Contact / Newsletter / Testimonial / Feedback / Security）统一品牌卡片；**客户邮件**：收据、分期催款、Booking 单发、Messages 群发均为深蓝顶栏品牌壳（Messages 正文仍为编辑器内容）  

### Reports

顶栏分两块：**Activity**（Trips / Bookings / Participants）与 **Money**（Expected / Discounts* / Paid / **Refunded*** / Pending；* 有值才显示）。口径与 Manage 页顶合计一致。分类条只汇总财务；人数看表格。订单操作仍进各行程 Manage。

## 四、客户报名

客户在行程页点 Book Now，弹窗内完成：

| 步 | 内容 |
|----|------|
| 1 | 选套餐、人数（Travelers ±）；有分期时看 Payment Schedule |
| 2 | 附加选项（如有） |
| 3 | 参与者信息（含护照等上传） |
| 4 | 购买者信息 |
| 5 | 支付：Stripe 刷卡；若折扣把「现在应付」抵成 **$0**，则无需刷卡直接确认 |

右侧 **Your Booking**：可输入折扣码；Trip Total 为行程总价，Due at Booking 为本次应付。

**支付**：Visa / Mastercard / Amex；由 Stripe 处理。**现网为 Test 模式**，真实收款（Live）尚未开通。

**分期**：先付定金 → 按约定付余款 → 系统按到期日自动发提醒 / 催款邮件（见下）。

**强制补齐**：客户点某一期的 Pay now 时，若前面还有未付/逾期期，应付金额会**自动加上此前欠款**（一次付清这些期）。成功后只有**一笔**收款、**一张**收据（Includes 列出各期）。客户要「第 1 期收据」时，给这张含第 1 期的补齐收据即可，不要另造空收据。仍可用页面上的 Payoff 一次结清整单剩余。

**Payoff 在后台**：Manage 订单列表 Fully Paid 旁会有紫色 **Payoff**；打开订单后 Payment History 有说明与紫色标签，被取消的分期显示 `cancelled (payoff)`。Payments 页展开订单也能看到 Payoff 行。

### 分期邮件提醒规则

系统每天约 **美西上午 9:00**（`America/Los_Angeles`）自动扫描：订单 **未取消**、分期 **未付清** 的记录。匹配到期日用**美西日历日**（与客户约定的 due date 一致）。与 Messages 人工群发无关（Sent 列表不含这些系统信）。

| 时机 | 邮件类型 | 说明 |
|------|----------|------|
| 到期前 **3 天** | Payment Reminder | 首次到期前提醒（该期尚未发过提醒时） |
| 到期前 **1 天** | Payment Reminder | 二次提醒 |
| **到期当天** | URGENT / Due Today | 当天提醒 |
| **已逾期** | Overdue payment notice | 约每 **3 天** 再催一次；该期总提醒次数（含到期前）约 **最多 6 次** 后停止自动催 |

邮件内有 **Pay now**，打开带签名的付款页（`/pay-installment/…?token=…`），可付当期或勾选 PAY OFF 结清剩余。发件人为 `noreply@`；页脚引导联系 **info@nhtours.com**。

若订单在账本上已结清（`amount_due ≤ 0`，例如已 Pay off），系统会跳过催款并取消未付分期。

**追缴期**：报名日之前已到期的分期会并进首付；落库为已付并标注「Included in initial payment」，**不会再催该期**。

**后台**：Payments / 订单相关处可对单期 **手动发送提醒**（不必等定时任务）。

**注意**：测试报名若未取消、分期未付，到期后也会进入上述催款流程。测完请 **取消测试订单** 或将该期标为已付，避免误催自己或测试邮箱。

**确认与收据**：

- 邮件标题一般为 Payment Receipt；编号为 **Order number**
- 邮件含 **PDF 附件**，以及蓝色按钮 **Download Receipt (PDF)**（链接带签名 token，不能仅凭订单数字 id 下载）
- 收据 **Trip Total** 顺序：Total Expected → Due this time（**当笔收款**；下方 Includes 说明 Initial/分期/Payoff）→ Amount Paid → Amount Remaining
- **客服下某期收据**：Manage 打开订单 → Payment History 找到对应行（如 Installment #3）→ 点 **Receipt** → 把 PDF 发给客户；底部 **Generate Receipt** = 最近一笔成功付款
- **单笔收据口径**：Due this time / Amount Paid / Remaining / History 都是**付完该笔当时**的状态（例如只下 Initial 时 Paid=定金、Remaining=当时余额），不是订单现在已全部付清后的快照
- 收据页眉左上角与页脚 logo 为同一品牌图
- **History 页**：仅 **一次付全款** 不要；定金/分期（哪怕只付了 1 笔）→ 第 2 页放 Payment History + 分期明细 + Refunds
- 另有 **Payment History**（每笔基础/卡费/实扣/已退）、**Installment Schedule**（含「报名时已逾期、已并进首付」的追缴期，标为 Paid / Included in initial payment）、有退款时列出 **Refunds**
- 版式定稿：`.cursor/rules/receipt-pdf-layout.mdc`；样例：`flask-app/docs/receipt-reference/`
- 若按钮失效：仍可用邮件附件；或联系客服并提供 Order number

## 六、常见问题

**如何改已发布行程？**  
行程管理 → **Edit** → 保存。

**Order number 和 id 有何区别？**  
Order number 给客户与对账；`id` 是系统主键（链接 / API 用），不必告诉客户。

**改标题或出发日，旧订单号会变吗？**  
不会。新缩写 / 新出发月只影响之后的新单。

**如何导出订单？**  
Manage → **Download Excel** → 静态快照（Participants / Contact / Bookings Summary / Canceled）。Excel 的 Participants 表仍含 Package、Payment Status（含 Refunded）、**Refunds**、Net Paid 等对账列（比网页 Tab 更全）；Summary / Canceled 也有 Refunds。Payments 页 → **Export** 可导出每笔支付的 Refunded、Net、Refund Reason、Refunded At（**字体/表头/金额格式与 Manage Excel 统一**，列内容不同）。打开即可用，无需「刷新数据源」。

**如何改管理员密码？**  
网页无入口；见 [安全手册.md](安全手册.md) → 轮换凭据。

**分期逾期怎么办？**  
系统会在到期前 3 天、1 天、当天发提醒；逾期后约每 3 天催一次（总提醒约最多 6 次），状态会标为 Overdue，后台可查。客户点邮件里的 Pay now 付款即可（会自动带上此前未付期）。详见上文「分期邮件提醒规则」。

**退款多久到账？**  
走 Stripe 的退款通常 5–10 个工作日到卡；Manual only 只改系统账，需另行处理银行 / Stripe。

**退多少？**
与客户谈妥后在退款框里**手填金额**即可（不超过该笔剩余可退）；请同时对照合同 / Terms。

**折扣码怎么用？**  
Trip Builder 第 7 步创建；客户在弹窗 Your Booking 输入。

**客户说收据下不了 / 样式没更新？**  
先让对方对网站 **Ctrl+F5**（`site-nav.css?v=…`）；站内按钮应为白底灰边 + 下载图标，点击直接下 PDF。仍异常时提供 Order number 与发生时间。

**客户付款失败？**  
失败页会显示银行/Stripe 返回的简短原因（如余额不足），并说明未扣款；可让对方换卡或联系发卡行后 **Try Again**。

**收据页头日期 / Due this time / Paid / Remaining**：均对应当前收据所选的那笔（Manage 行内指定；默认最近一笔）——**付完该笔当时**的累计已付与余额；第 2 页 History 也只列到该笔为止。

**安全日志 / SSH？**  
见 [安全手册.md](安全手册.md)（`ssh nhtours`、`nh-audit`）。
