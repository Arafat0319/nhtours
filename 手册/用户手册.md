- **管理员账户**
    - 凭据见 [安全手册.md](安全手册.md) → 凭据与地址，或本地 `安全手册-凭据.local.md`
    - **不能**在网页里改密码；轮换见安全手册「轮换凭据」

## 二、快速开始

- **流程**

    ```text
    登录后台 → 创建行程（7 步向导）→ 发布 → 把链接发给客户
    ```

- **步骤**
    - 1 — 打开 https://nhtours.com/admin/login，输入用户名密码
    - 2 — **My Trips** → **+ New Trip**，按向导填完并 **发布**
    - 3 — 复制行程链接发给客户，客户在线报名付款

---

## 三、后台管理

- **仪表盘 Dashboard**
    - 总行程数、总预订数、近期订单

- **行程 My Trips**
    - **列表**
        - 卡片视图 / 日历视图
        - 筛选：Upcoming、Past、Draft
    - **新建 Trip Builder（7 步）**
        - 1 — 基础信息：标题、日期、封面、人数
        - 2 — 详细描述
        - 3 — 套餐与价格（全款 / 分期）
        - 4 — 附加选项
        - 5 — 购买者信息字段
        - 6 — 参与者问卷
        - 7 — 折扣码
    - **行程内操作**
        - 报名列表、参与者、导出 Excel、编辑、发布/下架

- **订单**
    - **状态**
        - Pending — 待支付
        - Deposit Paid — 已付定金
        - Fully Paid — 全额已付
        - Cancelled — 已取消
    - **退款**
        - 订单详情 → **Refund** → 输入金额 → 确认

- **客户 Customers**
    - Customers — 已预订客户
    - Leads — 咨询未订客户
    - Testimonials — 首页评价 / Feedback 审核（批准后上首页轮播）

- **报表 Reports**
    - 总收入、各行程明细、待收款项

## 四、客户报名

- **客户步骤（行程页弹窗）**
    - 1 — 选套餐、人数、全款或分期
    - 2 — 附加选项（单房差、接机等）
    - 3 — 参与者信息
    - 4 — 购买者信息
    - 5 — Stripe 支付

- **支付**
    - 由 Stripe 处理（PCI DSS）
    - 支持 Visa / Mastercard / Amex
    - **当前生产为 Test（沙盒）模式**；真实收款（Live）尚未开通

- **分期**
    - 先付定金 → 按约定付余款 → 到期前系统发提醒邮件（须配置 SES 后邮件才会真正发出）

## 五、评价与反馈

- **首页 Testimonials**
    - 访客可在首页提交；后台 **Customers → Testimonials** 审核后出现在轮播

- **Post-trip Feedback**
    - 私有链接：`https://nhtours.com/feedback`（不进主导航，通常放邮件里）
    - 与 Testimonials 同表审核；批准后可上首页

## 六、常见问题

- **Q：如何修改已发布行程？**
    - 行程管理页 → **Edit** → 修改 → 保存

- **Q：如何导出订单？**
    - 行程管理页 → **Export** → 下载 Excel

- **Q：如何改管理员密码？**
    - 网页上没有改密入口
    - 见 [安全手册.md](安全手册.md) → 轮换凭据（GitHub Actions 或 SSH）

- **Q：分期逾期怎么办？**
    - 到期前 3 天、1 天发提醒（SES 配置后）
    - 逾期标为 Overdue；后台可查看

- **Q：退款多久到账？**
    - 后台发起后，通常 5–10 个工作日

- **Q：折扣码怎么用？**
    - Trip Builder 第 7 步创建
    - 客户在支付页输入，系统自动算价

- **Q：安全日志 / SSH 怎么查？**
    - 见 [安全手册.md](安全手册.md)（`ssh nhtours`、`nh-audit` / `nh-audit -a`）
