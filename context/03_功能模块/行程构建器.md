# 行程构建器 (Trip Builder)

Trip Builder 是后台管理系统的核心功能，提供 7 步向导式界面用于创建和编辑行程。

## 概述

### 功能定位

Trip Builder 让管理员能够：
- 创建新行程并设置价格方案
- 配置报名表单和参与者问卷
- 管理折扣码
- 发布行程供客户报名（自动：Basics + 有效 Description 正文 + ≥1 package；侧栏显示缺口；reactivate 不能绕过）

### 设计原则

- **分步引导**: 复杂表单拆分为 7 步，降低认知负担
- **即时保存**: 每步提交自动保存，支持中途退出
- **灵活配置**: 支持多套餐、多支付方式、自定义问题

## 步骤详解

### Step 1: 基础信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 行程标题 | ✅ | 显示在列表和详情页 |
| Slug | ✅ | URL 友好的唯一标识 |
| 开始日期 | ✅ | 行程开始时间（Flatpickr 日期选择器，Safari/Chrome 一致体验） |
| 结束日期 | ✅ | 行程结束时间 |
| 封面图片 | ✅ | Hero Image |
| 最大人数 | ✅ | 容量限制 |
| 日历颜色 | - | 5 个预设色块 + 自定义颜色（渐变调色板按钮） |

**技术细节**:
- 日期选择使用 **Flatpickr** 替代原生 `input type="date"`，解决 Safari 日历过小、点击外部不关闭等问题
- 日历颜色支持预设 + 自定义，自定义按钮为圆形渐变 + 调色板图标，点击打开系统颜色选择器

### Step 2: 详细描述

| 字段 | 必填 | 说明 |
|------|------|------|
| 行程描述 | - | Quill 富文本编辑器 |
| 包含项 | - | 动态列表（trip_includes） |
| 不包含项 | - | 动态列表（trip_excludes） |

**技术细节**:
- 使用 Quill.js 提供富文本编辑
- 包含/不包含项存储为 JSON 数组

### Step 3: 套餐管理

每个行程可配置多个套餐：

| 字段 | 说明 |
|------|------|
| 套餐名称 | 如 "标准套餐"、"VIP 套餐" |
| 价格 | 单价金额 |
| 货币 | USD / CNY / CAD |
| 库存 | 可选，限制该套餐销量 |
| 报名截止 | 超过此日期不可报名 |

**支付计划配置**:

```json
{
  "enabled": true,
  "deposit_amount": 500,
  "installments": [
    {"date": "2025-06-01", "amount": 1000},
    {"date": "2025-07-01", "amount": 1000}
  ],
  "enable_auto_billing": false
}
```

### Step 4: 附加选项 (Add-ons)

可选的增值服务：

| 字段 | 说明 |
|------|------|
| 名称 | 如 "单房差"、"接机服务" |
| 价格 | 单价 |
| 描述 | 简短说明 |
| 库存 | 可选限制 |

### Step 5: 购买者信息

配置报名时需要收集的购买者信息。与 Step 6 共用 **Add custom field** 入口，逻辑统一。

| 配置项 | 说明 |
|--------|------|
| 标准字段 | First Name, Last Name, Email, Phone 等 |
| 紧急联系人 | 可选开启 |
| 自定义字段 | 动态添加，类型与参与者问卷一致 |

**Field Type 分类**（与 Participant 统一）:
- **Text**: Text, Long Text, Number, Address
- **Contact**: Email, Phone
- **Choice & Other**: Dropdown, Yes/No with Details, Date

**BuyerInfoField 模型**:
- `field_type`: text / textarea / number / email / phone / address / date / select / yesno_text
- `options`: 选项配置（Dropdown 类型使用「Add option」逐项添加）
- `is_required`: 是否必填

### Step 6: 参与者问卷

为每位参与者配置需回答的问题。入口文案「Add custom field」与 Buyer Info 一致。

| 字段类型 | 说明 |
|----------|------|
| text | 单行文本 |
| textarea | 多行文本 |
| number | 数字 |
| email | 邮箱 |
| phone | 电话 |
| choice | 下拉选择 (Dropdown)，选项逐项添加 |
| date | 日期（Flatpickr 统一样式） |
| yesno_text | Yes/No with Details：选 Yes 时显示文本框，提示 "If yes, please explain:" |
| file | 文件上传 |

**Yes/No with Details**:
- 适用如「是否有过敏？」：选 No 无后续输入，选 Yes 显示文本框填写过敏原
- 数据格式：`{ value: "yes"|"no", details: "..." }`

### Step 7: 折扣码

管理本行程可用的折扣码：

| 字段 | 说明 |
|------|------|
| 折扣码 | 唯一字符串 |
| 类型 | percentage / fixed |
| 金额 | 折扣比例或固定金额 |
| 使用次数 | 限制总使用次数 |
| 过期日期 | 有效期限 |

## 技术实现

### 前端架构

```
templates/admin/trips/builder/
├── base_builder.html       # 公共布局（导航、进度条）
├── step_basics.html        # Step 1: 基础信息（Flatpickr、自定义颜色）
├── step_description.html   # Step 2: 描述编辑
├── step_packages.html      # Step 3: 套餐管理
├── step_addons.html        # Step 4: 附加选项
├── step_buyer_info.html    # Step 5: 购买者信息
├── step_participants.html  # Step 6: 参与者问卷
└── step_coupons.html       # Step 7: 折扣码
```

### 后端路由

| 路由 | 方法 | 功能 |
|------|------|------|
| `/admin/trips/new` | GET | 创建新行程，跳转 basics |
| `/admin/trips/<id>/builder/<step>` | GET | 显示步骤表单 |
| `/admin/trips/<id>/builder/<step>` | POST | 保存步骤数据 |

**step 参数值**: `basics`, `description`, `packages`, `addons`, `buyer_info`, `participants`, `coupons`

### 数据流

```
用户填写表单
    ↓
前端验证 (HTML5 + JavaScript)
    ↓
POST 提交到后端
    ↓
WTForms 验证
    ↓
保存到 Trip / TripPackage / CustomQuestion 等表
    ↓
重定向到下一步或返回表单显示错误
```

### JavaScript 模块

关键 JavaScript 功能：

1. **Flatpickr 日期选择**: Step 1 开始/结束日期，跨浏览器一致，支持点击外部关闭
2. **动态列表管理**: 添加/删除包含项、附加选项
3. **Quill 富文本**: 初始化编辑器，同步到 hidden input；Description **autosave**（约 400ms 防抖、排队、侧栏离开 flush）
4. **支付计划配置**: 动态添加分期日期和金额
5. **表单验证**: 实时提示必填项、图片类型/大小验证
6. **发布缺口提示**: 草稿侧栏列出尚缺字段（`publish_gaps`）

## 数据结构

### Trip 表关键字段

```python
class Trip(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(200), nullable=False)
    slug = db.Column(db.String(200), unique=True)
    status = db.Column(db.String(20), default='draft')
    
    start_date = db.Column(db.Date)
    end_date = db.Column(db.Date)
    capacity = db.Column(db.Integer, default=20)
    
    description = db.Column(db.Text)
    trip_includes = db.Column(db.Text)  # JSON array
    trip_excludes = db.Column(db.Text)  # JSON array
    
    hero_image = db.Column(db.String(500))
    color = db.Column(db.String(7))
    
    # Relationships
    packages = db.relationship('TripPackage', backref='trip', lazy='dynamic')
    addons = db.relationship('TripAddOn', backref='trip', lazy='dynamic')
    questions = db.relationship('CustomQuestion', backref='trip', lazy='dynamic')
```
