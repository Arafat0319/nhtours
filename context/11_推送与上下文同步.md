# 推送与上下文同步

`git push origin main` 触发生产 Deploy **之前**，须同步 `context/`。细则亦见 `.cursor/rules/*.mdc`。

## 同步检查表

| 改动类型 | 更新文档 |
|----------|----------|
| 模型/迁移 | `02` |
| 路由/API | `04` |
| 功能状态 | `08` |
| UI | `05` |
| 部署 | `06` |
| 概览 | `00` |
| **任何 push** | **`07`（至少一条）** |
| 表单链路 | `09` |

核对：`routes.py` → grep `@bp.route` 对 `04`；`models.py` → 对 `02`。

## 流程

```
改代码 → 更新 context（含 07）→ 用户本地测完并同意 → commit（代码+context）→ push → 查 Actions
```

## Push 前自检

- [ ] 检查表内适用文档已更新
- [ ] `07` 有当日条目
- [ ] context 与代码将同一 commit
- [ ] 未写入密钥/`.env` 真实值
