## 设计原则

### 改视觉须用户同意

AI / 开发助手在测试、优化、排查过程中**不得擅自**改动页面前端视觉；需要改布局、文案呈现、颜色、间距、样式时，须先征得用户同意。详见 `AI_快速参考.md`「硬性准则」与 `.cursor/rules/no-frontend-visual-without-approval.mdc`。

### WeTravel 风格

后台管理系统采用 WeTravel 风格设计：
- **简洁明亮**: 白色背景 + 青色主色调
- **卡片布局**: 信息块使用卡片承载
- **清晰层级**: 通过阴影和间距区分层级

### 技术选型

| 技术 | 用途 |
|------|------|
| Tailwind CSS | 样式框架 |
| Heroicons | SVG 图标 |
| Quill.js | 富文本编辑器 |
| Flatpickr | 日期选择器（Safari/Chrome 一致） |

  </label>

                placeholder-gray-400">
</div>

### 下拉选择

管理平台内所有 `<select>` 统一使用 `admin-select` 类，以自定义箭头样式并保持右侧间距（箭头距右边缘约 0.5rem）。

```html
<select class="admin-select w-full px-3 py-2 border border-gray-300 rounded-lg 
               focus:ring-2 focus:ring-wetravel-cyan focus:border-wetravel-cyan">
  <option>选项 1</option>
  <option>选项 2</option>
</select>
```

**admin-select 样式**（定义于 `base_wetravel.html`）:
- `appearance: none` 移除浏览器默认箭头
- 自定义 SVG chevron 背景图，`background-position: right 0.5rem center`
- `padding-right: 2rem` 确保文本与箭头不重叠
- 固定高度 `h-9` / `h-8`：`line-height` 等于高度、上下 padding 清零（修 Windows 文字贴顶）；勿再叠 `sm:leading-6`

### 日期选择器 (Flatpickr)

项目内日期选择器统一使用 Flatpickr（Trip Basics 风格），覆盖：Trip Builder、报名表单、管理后台、套餐配置。

| 配置 | 说明 |
|------|------|
| 引入 | `base_builder.html` 引入，`trip_booking.html` / `manage.html` 各自引入 |
| 格式 | `dateFormat: 'Y-m-d'` |
| 行为 | `static: false`（点击外部关闭） |
| 样式 | `.flatpickr-calendar { font-size: 16px }`，日期格铺满宽度；`.flatpickr-day` 约 38×38 |
| 触发 | 输入框加 `fp-date` class，调用 `initFlatpickrOnDates()` 初始化 |

**报名弹窗 Date of Birth（额外）**：

| 项 | 说明 |
|----|------|
| 月/年 | 自定义 Uiverse 下拉（同 Gender），非原生 select / 翻页箭头 |
| 选中态 | 淡蓝底 `rgba(0, 102, 255, 0.1)`（`.booking-select-has-value`） |
| 关闭 | 选月/年不关日历；选日或点外部关闭 |
| 文件 | `trip_booking.html` 内联样式与 `attachBookingMonthDropdown` / `attachBookingYearDropdown` |

### Yes/No with Details

自定义字段类型 `yesno_text`：选 No 无后续输入，选 Yes 显示文本框，上方提示 "If yes, please explain:"。适用于过敏、特殊需求等场景。数据格式 `{ value: "yes"|"no", details: "..." }`。

### Dropdown 选项配置

在 Add custom field 中选择 Dropdown 后，选项通过「Add option」逐项添加，每行一个输入框 + 删除按钮。选项输入框样式与 Field Name / Question Label 一致。

### 颜色选择器（自定义按钮）

当需「预设 + 自定义颜色」时，自定义入口采用圆形渐变按钮：

| 元素 | 样式 |
|------|------|
| 外层 | `rounded-full`，`border-2 border-gray-200`，`hover:border-wetravel-cyan` |
| 背景 | 渐变 `from-cyan-400 via-pink-400 to-amber-400` |
| 图标 | 调色板 SVG，`text-white drop-shadow-sm` |
| 原生 input | `type="color"`，`opacity-0` 覆盖，点击触发系统颜色选择器 |
| 选中态 | `ring-2 ring-offset-2 ring-gray-400` 与预设色块一致 |

## 报名页主内容区 (trip_booking #main-content)

报名页主内容区（About this trip、What's included、Available Packages 等）的标题与间距统一在 `trip_booking.html` 内联样式中定义。

### 标题层级 (h2～h6)

| 标签 | 字号 | 说明 |
|------|------|------|
| h2 | 1.5rem | 如 Itinerary |
| h3 | 1.375rem | 如 About this trip、What's included、What's not included、Available Packages、Available Add-Ons |
| h4 | 1.25rem | 预留 |
| h5 | 1.125rem | 预留 |
| h6 | 1rem | 套餐名称、Add-on 名称（卡片内小标题） |

统一样式：`font-weight: 600`、`letter-spacing: 0.025em`、`color: #27272a`、`text-transform: uppercase`、`padding-bottom: 0.375rem`、`text-align: left`。  
套餐名与 Add-on 名使用 h6 时通过 `.trip-packages-box .package-info h6`、`.trip-addons-list .addon-info h6` 覆盖为 `text-transform: none`，保持正常大小写。

### 间距规范

| 类型 | 数值 | 说明 |
|------|------|------|
| 标题与内容 | 0.375rem | 各标题的 `padding-bottom`，标题与下方正文/列表的间距 |
| 区域与区域 | 2.5rem | `#main-content.trip-main-content-sections > section + section` 的 `margin-top`，各 section 之间统一 |

区域间距大于标题与内容间距，且所有 section 一致（不再对 includes/excludes/packages/addons 单独设 `padding-top`）。

### 组织者卡片图标与文字

地点、日期、Group size 的图标与文字间距使用 `gap-2`（8px），保证与 teal 图标视觉上略松。

### 区块类名（WeTravel 风格）

- **区块**：主内容各 section 使用 `trip-page__section`，标题使用 `trip-page-section__header`，与 WeTravel 行程页 DOM 命名对齐。（Sticky 导航已按需求移除。）

### 报名弹窗 (booking modal)

- **遮罩**：`rgba(39, 43, 43, 0.88)`；仅关闭按钮可关闭，点击遮罩不关闭。
- **弹窗打开时**：顶部固定 Nav（`#pageNav`）隐藏（`visibility: hidden`）；Logo 在**屏幕左上角**固定显示（`fixed`，left 1.5rem / top 1rem，z-index 10002），尺寸 256×57.69px，与 Nav 同款 `logo-2-white`。
- **卡片**：max-width 870px，圆角 0.5rem，顶部留白 60px。
